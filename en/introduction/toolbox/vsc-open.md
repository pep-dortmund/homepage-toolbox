# VSCodium/VSCode (VSC): Opening folders and terminals

1. Open VSC and go to {gui}`File > Open Folder`. 
   The keyboard shortcut for your operating system is displayed there as well,
   e.g., first {kbd}`Ctrl` + {kbd}`k` then {kbd}`Ctrl` + {kbd}`o`. 
   In the window that appears, navigate to the folder
   you want to work in and open it.
   ```{image} /img/introduction/VSCode_NewDir1.png
   :alt:
   :align: center
   ```
2. If you are in a terminal, you can navigate to the desired folder using {kbd}`cd`. 
  Once there, you can open the folder in VSC using {kbd}`codium .` (if you have VSCodium installed)
  or {kbd}`code .` (for VSCode on Windows).

In VSC, you can open a terminal inside VSC by right-clicking on one of the files.

```{image} /img/toolbox/VSCode_0.png
:alt:
:align: center
```
